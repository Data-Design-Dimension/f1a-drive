# User testing kit

## Consent
Read aloud; parent/guardian sign-off for under 18.

"I am testing an audio app idea, not you. You can stop anytime. I will not share your name. Audio you record stays on this device unless you say otherwise. Is it OK to continue?"

## Fan session (10 min)

	1.	When in your day would you listen to your favorite driver? (open answer; probe: before/after, how long, alone or with someone)
	2.	Play sample note. What did you feel? Would you replay it?
	3.	Show theme bubbles. What do you tap first? What is missing?
	4.	After you vote, what do you expect to happen?
	5.	Would you send a voice reply? What would stop you?
	6.	1-5: How inspired do you feel? How safe does it feel?

## Driver session (10 min)

	1.	When could you record a 60-sec note without it feeling like work?
	2.	Which theme would you pick first? Which would you skip?
	3.	How would you want to hear or see fan input: bubbles, one reply per weekend, other?
	4.	What would make you stop using it?

## A/B tests

| Test | A | B | Measure |  
| —-- | —-- | —-- | —-- |  
| Timing | note at 7:30am | note at 4pm | listen-through rate |  
| Content | pep talk | raw practice-lap audio | completion, replay |  
| Length | 30 sec | 90 sec | drop-off point |  
| Trigger | wake phrase | push notification | next-day reuse |  
| Voting UI | growing bubbles | ranked list | votes per session |  
| Reply | voice reply | emoji only | reply rate, driver hears it |  

Sample: 5-8 fans, 2-3 drivers or driver-adjacent contacts.
